# Online-Mind2Web runs, October 2026

Every run behind the README's numbers, in time order. Tasks are from [Online-Mind2Web](https://huggingface.co/datasets/osunlp/Online-Mind2Web) (CC BY 4.0). Each was run once by Codex `gpt-6.1-sol` at low reasoning in Chrome for Testing on New York time and graded by a port of the benchmark's WebJudge (`bench/om2w/run.mjs`). Agent runs time out at 15 minutes.

- **rounds:** the hard tasks, four rounds with fixes in between (notes on), through a US VPN.
- **notes test:** new tasks on explored sites, notes on (`reflect`) vs off.
- **head to head:** Codex's own browser vs browserctrl, both without notes. The second Airbnb pair ran after the fixes in `e314406`.
- **held-out rounds 1–3:** hard tasks on sites never used while fixing, chosen before each round's fixes (`bench/om2w/splits.json`), one run per method. Rounds 1–2 through a US VPN with the one-call judge; round 3 over a direct connection with the full judge and a harness that treats both methods identically (settings in the environment, the same screenshots). Each round was retired into dev after it was studied.
- **final:** 21 hard tasks on 17 sites never used while fixing, chosen before any of them was run, one run per method (2026-10-17). Three native runs and one browserctrl run were redone: the native browser tool stopped answering for about 20 minutes, and a test on the same machine restarted browserctrl's background process during one run. The redone runs are marked *superseded*. **hand check** is the verdict from each run's own log, answer and stills (`bench/om2w/handcheck.json`); the automatic judge grades stills only and failed 14 runs whose logs show the task done.

Rescored verdicts: two round-run verdicts after judge fixes (the run date; a forbidden purchase). Known disputed verdicts left as judged: round-2 Wine Access, Healthline and Speedo (see the README). Run folders with recordings, prompts, agent events and judge output stay local under `bench/om2w/runs/`.
