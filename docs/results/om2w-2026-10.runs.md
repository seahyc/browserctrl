# Online-Mind2Web runs, October 2026

Every run behind the README's numbers, in time order. Tasks are from [Online-Mind2Web](https://huggingface.co/datasets/osunlp/Online-Mind2Web) (CC BY 4.0). Each was run once by Codex `gpt-6.1-sol` at low reasoning in a US-routed browser on New York time and graded by a one-call port of the benchmark's WebJudge (`bench/om2w/run.mjs`). Agent runs time out at 15 minutes.

- **rounds:** the hard tasks, four rounds with fixes in between (notes on).
- **notes test:** new tasks on explored sites, notes on (`reflect`) vs off.
- **head to head:** Codex's own browser vs browserctrl, both without notes, in Chrome for Testing. The second Airbnb pair ran after the fixes in `e314406`.
- **held-out (rotation 1):** 10 hard tasks on sites never used while fixing, chosen before the fixes in `b626272` (`bench/om2w/heldout.txt`): Codex's own browser once, browserctrl before and after those fixes. Retired into dev afterwards (`bench/om2w/splits.json`).

Verdicts for two runs were rescored after judge fixes (the judge was not told the run date; it failed a run for not completing a forbidden purchase). Run folders with recordings, prompts, agent events and judge output stay local under `bench/om2w/runs/`.
